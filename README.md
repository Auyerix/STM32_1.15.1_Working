# Repo de Trabajo en STM32 IDE 1.15.1 

## Uso del repositorio

En este repo se guardan todas las revisiones de stm32cubeIDE realizadas de los distintos proyectos

BlackPill_01 es un proyecto en blanco para la BlackPill STM32F401

BlackPill_00 es un proyecto en blanco para la BlackPill STM32F411 (no probado)

BlackPill_01_SIM76XX_01 BlackPill STM32F401 con comunicación 4G con SIM MQTT y Certificados

BlackPill_PWM01 BlackPill STM32F401 proyecto base PWM para control de lámparas con relé de estado sólido para hornos flash

LWIP_TCP_SERVER_CLIENT_NETCONN5 es la revisión final del Proyecto PLCNext - Modbus presentado en la Especialización
